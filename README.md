# Supply Chain Analytics Dashboard

## Project Overview

This project focuses on analyzing supply chain operations data to identify
inventory trends, supplier performance, order status patterns, and delivery
efficiency.

The analysis was performed using **SQL and Python** to clean, transform,
and analyze structured datasets. Business insights were generated to
understand operational performance and identify improvement opportunities.

---

## Objectives

- Analyze supply chain performance metrics
- Identify inventory levels and stock-related issues
- Evaluate supplier delivery performance
- Analyze delayed and completed orders
- Generate insights from operational data

---

## Tools & Technologies

- **SQL** - Data querying, filtering, aggregation, and analysis
- **Python** - Data processing and exploratory data analysis
- **Pandas** - Data cleaning and transformation
- **Matplotlib** - Data visualization
- **Excel** - Data analysis and reporting

## Dataset Description

The dataset contains supply chain transaction records with information such as:

- Order details
- Product categories
- Supplier information
- Regional performance
- Inventory levels
- Order status
- Quantity ordered
- Shipping cost
- Delivery lead time

---

## Analysis Performed

### Data Cleaning

- Checked dataset structure and missing values
- Validated data consistency
- Prepared data for analysis

### SQL Analysis

Performed queries to analyze:

- Total orders and quantity
- Order status distribution
- Supplier performance
- Region-wise performance
- Product category analysis
- Delayed orders
- Inventory levels

### Exploratory Data Analysis

Analyzed:

- Order completion trends
- Delivery delays
- Inventory availability
- Supplier lead time patterns
- Category-wise demand

## Key Insights
